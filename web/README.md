# Web application (planned)

The application will use Svelte and MapLibre GL JS for city exploration, intervention editing, simulation status, multimodal accessibility maps, before/after comparisons, and provenance/uncertainty review. No UI scaffold has been generated yet.

E02-S01 currently provides a Rust CLI that generates an accessible standalone
HTML/SVG city/metro boundary preview. See [geography search](../docs/GEOGRAPHY-SEARCH.md)
for usage and the exact three-area pilot coverage. This does not introduce the
Svelte/MapLibre application or an HTTP service.
