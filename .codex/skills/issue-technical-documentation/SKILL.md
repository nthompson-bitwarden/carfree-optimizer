Primary owns documentation by default. Inspect candidate/diff for API, schema,
configuration, commands, errors, provenance, units, uncertainty, and compatibility
impact. Update existing guides; ADRs distinguish proposals from validated choices.
Use Mermaid only when useful; check links/examples and report unverified rendering.
Record no-change rationale when appropriate. Authorized documentation commits
precede independent final checks/review; reassess impact after corrections.

Follow shared scope, handoff, model, and evidence rules in docs/AGENT-WORKFLOW.md.
Workers do not delegate, commit, or publish.
